Everything below runs client-side with WebCrypto AES-256-GCM. The server never receives your plaintext or decryption key.

Paste your message

Type or load a sample team message. Unleak finds live keys mid-sentence without altering the rest of your text.

03

Verify bot immunity & one-time burn

Chat apps send a GET request to build a link preview. Test both actions on any link to see how preview bots are ignored while a human reveal wipes the secret from memory once.

04

Post-burn rotation order
